  1. CONVEX PRODUCTION DEPLOYMENT

  2. PRODUCTION ENVIRONMENT VARIABLES

     (Freebuff/Vercel/Vercel dashboard)

  3. ADMIN ACCOUNT SETUP
     - Deploy to production
     - Visit /auth
     - Sign up with email
     - Click "Become Admin" (first user only)
     - This grants admin access permanently

  4. SEED INITIAL DATA
     - After admin login, go to Dashboard > Overview
     - Click "Seed Data" button
     - This populates 10 procedures, 3 testimonials,
       6 FAQ entries, and default settings

     - Go to Dashboard > Settings
     - Enter real WhatsApp number in international format
       (e.g., +966XXXXXXXXX)
     - This is used for the consultation flow

  6. CONFIGURE REAL CONTENT
     - Upload doctor profile image
     - Upload hero image
     - Edit doctor biography
     - Edit contact information
     - Upload procedure images
     - Set real prices if desired
     - Configure social media links
