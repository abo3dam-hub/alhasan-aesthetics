5. SEO OG IMAGE
============================================================

BEFORE:
  SEOTab.tsx line 73: <Input value={form.ogImage || ""}
  onChange={...} placeholder="https://..." />
  → Admin had to manually paste image URLs

AFTER:
  SEOTab.tsx: <MediaSelector value={form.ogImage || ""}
  onChange={(url) => update("ogImage", url)}
  label="Select OG image" />
  → Admin can browse/search Media Library, select image,
    preview, replace, remove — no URL copy/paste needed

PERSISTENCE VERIFIED:
  - Form saves to siteSettings key "seo" via setSetting
  - Landing.tsx reads seoCMS.ogImage and applies as
    og:image meta tag
  - Full chain: Admin → MediaSelector → save → ogImage
    persisted → public og:image tag renders
