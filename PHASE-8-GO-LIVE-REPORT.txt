5. DYNAMIC SITEMAP
============================================================

Status: IMPLEMENTED

Architecture:
  1. Convex HTTP endpoint at /sitemap.xml
     - Queries active procedures from database
     - Includes all static routes
     - Reflects current CMS state
     - Cache-Control: 1 hour
     - No manual updates needed when procedures change

  2. Static fallback at public/sitemap.xml
     - Contains all static routes + seed procedure URLs
     - Served as fallback if dynamic endpoint unavailable
     - Updated with comments explaining the architecture

Files changed:
  src/convex/http.ts — Added /sitemap.xml HTTP route
  public/sitemap.xml — Updated with documentation
  public/robots.txt — Updated with admin exclusions

How it works:
  - When a new procedure is published via Admin CMS,
    the dynamic sitemap automatically includes it
  - When a procedure is unpublished/hidden, it's excluded
  - When a procedure is deleted, it disappears
  - No manual sitemap editing required
